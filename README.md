# OrthoGrafter

OrthoGrafter is an algorithm designed to determine the set of orthologs when provided with a graft position in the set of PANTHER gene trees such as those generated by the TreeGrafter software ( https://github.com/pantherdb/TreeGrafter ). OrthoGrafter updates the set of initial graft points provided by TreeGrafter to reconcile them with the reconciled PANTHER trees they are placed in. 

Currently OrthoGrafter can be run using Rscript with R.
